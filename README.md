# ASCII LENS

ASCII LENS is a Vite + React app for turning images into stylized ASCII artwork.

## Public URL

https://asciilens.indieapril.fun/

## Web Analytics

AsciiLens uses standard Vercel Web Analytics for automatic pageviews on Vercel-hosted production. See [docs/vercel-web-analytics.md](docs/vercel-web-analytics.md).

## Development

Install dependencies:

```bash
npm install
```

Run the app locally:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
